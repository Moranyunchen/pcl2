## 🚀 使用方法（4 步）

1. 在本仓库文件列表点 `Plain Craft Launcher 2.7z`，再点右上角 **Download** 下载
   （直链：`https://github.com/Moranyunchen/pcl2/raw/main/Plain%20Craft%20Launcher%202.7z`）；
2. **解压**：多数解压工具会生成一个 `Plain Craft Launcher 2` 文件夹，**里面的 `Plain Craft Launcher 2.exe` 才是要用的文件**（有的工具直接解出 exe，效果一样）。Windows 11 双击/右键即可解压；Windows 10 装过 7-Zip、Bandizip、WinRAR 都能解（无密码，若提示输密码说明文件被换过，别用）；
3. 把 exe 放到你原来的 PCL 目录，覆盖同名文件（建议先把新版 exe 改名留档，如 `PCL-2.99.bak`）；
4. **先退出 PCL**，用记事本打开 `PCL\Setup.ini`，在文件末尾新增一行：

   ```ini
   SystemSystemUpdate:3
   ```

保存后重新打开 PCL，`设置 → 启动器 → 启动器更新` 显示为关闭 = 成功。

> ✅ 只替换 exe **不会影响** `.minecraft`、存档、模组、按键设置等，它们都在旁边的文件夹里。
> ❗ 如果只想关更新、不换版本，也可以直接做第 4 步（适用于还没更新到 2.99.0.0 的旧版）。

## 🔐 安全校验（务必花 1 分钟）

**第一步：校验压缩包。** 在 7z 文件所在文件夹按住 `Shift` + 右键 →「在此处打开终端 / PowerShell」，执行：

```powershell
certutil -hashfile "Plain Craft Launcher 2.7z" SHA256
```

输出与上面的「压缩包 SHA-256」**一致**，说明压缩包是原版、没被换过。

**第二步（更稳）：校验解压出的 exe。**

```powershell
certutil -hashfile "Plain Craft Launcher 2.exe" SHA256
```

输出与上面的「exe SHA-256」一致，说明里面的程序也没被动过。

两条都对上，就可以放心用。仍不放心，可把文件上传 [VirusTotal](https://www.virustotal.com) 或用火绒 / Windows Defender 复查。

> ⚠️ **不要**下载群里转发的“修改版 / 免更新版 / 绿色便携版”，也不要运行要求你关闭杀毒软件的 exe。
> 只认本仓库地址 + 两级哈希一致，这是最省事的判断方式。

### 🛡️ 担心的话，本地杀软扫一遍（以及它的局限）

1. 解压出 `Plain Craft Launcher 2.exe`；
2. 右键该文件 →「使用火绒安全软件扫描」（火绒 6.0 支持把“病毒扫描”加入右键菜单，也可在火绒里「病毒查杀 → 自定义查杀」选中那个文件夹）；
3. 没装火绒：用 Windows Defender 右键「扫描」，或把文件拖进 [VirusTotal](https://www.virustotal.com) 做多引擎复核；
4. 结果怎么读：
   - **无报毒** → 可以作为参考，但**不等于 100% 无毒**（杀软只能识别已知特征和启发式行为，新病毒、加壳、白利用都可能扫不出）；
   - **有报毒** → 先核对 SHA-256：哈希一致说明文件没被换过，大概率是**未签名程序的误报**（PCL 原版本来就没有数字签名），再用 VirusTotal 多引擎确认；
   - **哈希不一致** → 不用管杀软怎么说，直接删掉重新下载。

## ❓ 常见问答（整理自 B站 / 社区，2026-10-20）

> 以下内容为社区整理版本，个别细节未获官方证实，仅供参考。

**Q1：到底发生了什么？**
A：有“神人小孩哥”往某个私服充钱，之后被家长发现，反手把私服举报了，顺手把 PCL 启动器一起举报。因此 PCL 决定关闭 MC 下载功能避避风头，其他第三方启动器也会跟进。

**Q2：和网易有关系吗？**
A：显然没关系。不过你可能会发现应用商店里下载不了网易《我的世界》了——这实际是网易和应用商店搞渠道服，而网易 MC 的渠道服去年就陆陆续续开始关了，应用商店没钱赚自然就不提供官方下载了。像 TapTap 或网易官网这种官方渠道还是能正常下载的。

**Q3：怎么好多人说是谣言？**
A：“小孩哥给私服充钱”“PCL 被连带举报”“PCL 关闭下载功能”都是真的，龙腾猫跃自己都在爱发电和 PCL 内群发过，能证明；其他的是基于这几点半真半假混在一起，要分清楚。

**Q4：那现在还能玩 MC 吗？**
A：已经下载的还能玩。事实上，如果你用*某种手段*关闭 PCL 更新，你也可以正常下载——毕竟被举报的不是下载源。

**Q5：那以后还能下载 MC 吗？**
A：不好说，目前还是避风头，要避多久不知道。不过破局之法其实很明显：直接从官方启动器下载版本，再手动安装 Fabric、NeoForge 等加载器一样玩，只是费点脑筋；谁今晚直接开发一个独立下载器也没准。

**Q6：修改版的 PCL 有用吗？**
A：**不要下载，不要下载，不要下载！** 那些所谓“修改版”和包含在转发消息里的旧版本 PCL，有很多是带病毒的版本，真用了电脑就中毒了，不要乱下载。

**Q7：有办法关闭 PCL 更新吗？**
A：有的。如果你还没更新版本，启动器本体旁边有一个名为 `PCL` 的文件夹，在里面找到 `Setup.ini`，用记事本打开，把 `SystemSystemUpdate` 的值改成 `3`；找不到这一项就自己加一行 `SystemSystemUpdate:3`。

**Q8：我已经打开了，现在只有个弹窗和“更新”按钮怎么办？**
A：右键任务栏图标把它关掉，再按 Q7 的方法关闭更新即可。

**Q9：我已经更新了，现在已经关闭下载了怎么办？**
A：只能找你信得过的人要个旧版。考虑到这条消息可能被到处转发修改，所以本仓库提供了**带两级 SHA-256 校验的 7z 原版包**——先核对压缩包哈希，再核对解压出的 exe 哈希，两个都对上就是原版，对不上千万别用。
